# Database Schema

The backend uses SQLAlchemy ORM backed by SQLite. Below are the primary entities in the system.

## 1. SolarData
Stores historical environmental and generation data used for ML training.
- `id` (Integer): Primary Key
- `timestamp` (DateTime): Measurement time
- `solar_generation_kw` (Float): Actual output
- `temperature`, `humidity`, `cloud_cover`, `wind_speed` (Float): Weather features
- `hour`, `day_of_week`, `month` (Integer): Time-encoded features for ML

## 2. Load
Represents appliances or system demands in the microgrid.
- `id` (Integer): Primary Key
- `name` (String): Human-readable name (e.g., 'Water Pump')
- `load_type` (String): 'essential' (cannot be shifted) or 'flexible' (can be deferred)
- `power_kw` (Float): Energy consumption rate
- `duration_hours` (Float): Execution time required
- `earliest_start`, `latest_finish` (String): Flexible boundary limits (HH:MM)
- `priority` (String): 'high', 'medium', 'low'

## 3. BatteryConfig
Stores current energy storage state and hardware limitations.
- `id` (Integer): Primary Key
- `capacity_kwh` (Float): Total battery size
- `current_soc`, `minimum_soc`, `maximum_soc` (Float): State of charge limits
- `max_charge_kw`, `max_discharge_kw` (Float): Transfer rate constraints

## 4. Forecast
Stores generated predictions from the ML pipeline.
- `id` (Integer): Primary Key
- `timestamp` (DateTime): Target time
- `predicted_generation_kw` (Float): Predicted solar generation
- `confidence_score` (Float): Model certainty metric

## 5. Schedule
Records individual scheduled slots generated by the scheduling engine.
- `id` (Integer): Primary Key
- `run_id` (String): UUID mapping to the specific experiment run
- `load_id` (Integer): Foreign key to the Load
- `scheduled_start`, `scheduled_end` (String): Selected time slot
- `status` (String): 'SCHEDULED', 'CONFLICT', 'SKIPPED'
- `explanation` (Text): Human-readable reasoning for the AI evaluator

## 6. ExperimentResult
High-level aggregator for A/B testing scheduler versions.
- `id` (Integer): Primary Key
- `run_id` (String): UUID
- `schedule_type` (String): 'baseline' or 'optimized'
- `renewable_self_consumption_pct` (Float): Core KPI
- `deadline_violations` (Integer): Number of dropped loads
